# 🚇 부산 지하철 역별 이용객 수 지도 분석 앱

Streamlit과 Folium을 활용하여 부산 지하철 역의 위치와 역별 이용객 수를 원형 마커 크기 및 호선별 색상으로 시각화하는 웹 애플리케이션입니다.

---

## 📌 주요 기능
1. **CSV 업로드 및 데이터 전처리**: `busan_subway.csv` 업로드 지원 및 숫자의 쉼표(,) 예외 처리
2. **이용객 상위 5개 역 표시**: 선택된 호선 내 이용객 수 Top 5 역 표시
3. **호선 필터링**: `st.multiselect`를 이용한 원하는 호선 선택 조회
4. **인터랙티브 지도 시각화**:
   - 이용객 수 제곱근 비례 반지름 반영
   - 호선별 색상 구별 (1호선: 주황, 2호선: 초록, 3호선: 갈색, 4호선: 파랑)
   - 마우스 Hover 시 역명, 클릭 시 이용객 수 Popup
